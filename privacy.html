隐私政策 (Privacy Policy)

最近更新日期：2026 年 11 月 20 日 · 适用平台：macOS / iOS / Android / Windows 全端通用

欢迎使用 透镜 (TransEase)（以下统称“本软件”或“我们”）。我们高度重视用户的个人隐私与数据安全。本隐私政策旨在向您说明透镜在运行过程中如何处理、保护您的数据，以及我们在系统级权限调用上的严格安全边界。

一、核心原则：本地优先与数据最小化

透镜的产品设计原则是“本地优先（Local-First）”与“数据主权归属用户”。我们不会为了商业变现或数据分析而收集您的屏幕内容、语音对话或日常操作记录。

二、系统权限的使用与必要性说明

为了在 macOS 或后续移动端上实现实时原位翻译与视频字幕功能，本软件需要向操作系统申请特定权限。我们对这些权限的使用范围做出如下严格承诺：

  • 屏幕录制权限（ScreenCaptureKit / Screen Recording）： 仅用于捕获您主动触发翻译的屏幕区域（随动透镜范围或顶层窗口）。所有捕获到的图像帧仅在系统易失性物理内存中进行 OCR 光学字符识别，提取文字完成后图像帧立即在内存中销毁，绝不向任何外部服务器上传截屏或录屏，绝不在本地磁盘落地留存。
  • 辅助功能权限（Accessibility API）： 仅用于全局快捷键（如 ⌥ Option + X）的响应、鼠标悬停位置探测以及在鼠标划选文本时获取待翻译的文本内容。本软件绝不记录您的键盘击键历史（Keylogging），绝不窃取用户密码或账户输入信息。
  • 麦克风与音频内录权限（Microphone & System Audio）： 仅在您主动开启“实时视频字幕（⌥V）”或“倾听同传（⌥L）”功能时调用。系统音频流仅用于本地语音特征提取与分词，音频数据随用随弃，绝不存储音频原声。

三、翻译请求与第三方网络交互

当本软件识别到待翻译的文本后，会将纯文本字符串发送至翻译引擎。关于网络请求的具体说明：

  • 用户自主配置直连：若您在设置中启用了“百度翻译官方直连”，软件直接使用您自备的官方 App ID 与密钥调用百度官方开放接口，通信全程通过 HTTPS 加密，直接往返于您的电脑与官方服务器之间。
  • 零中继服务器：开发者团队没有架设任何用于中转或嗅探用户翻译文本的中间服务器。您的翻译内容不会经过任何第三方中间人。
  • 网络代理支持：如果您配置了本地代理端口（如 127.0.0.1:7890），底层网络请求将严格遵循您的系统或本地代理规则转发，保障网络连通性。

四、数据存储与持久化政策

  • 用户配置数据：您的快捷键习惯、首选语言、代理设置以及百度 API Key 等敏感设置项，均加密存储于您本机的 macOS UserDefaults 或受保护的本地偏好文件中，绝不上传云端。
  • 翻译历史记录：视频字幕的全文抽屉或翻译历史仅在当前会话的本地内存中维护（上限 120 句），您可以随时点击“清空历史”或关闭软件，所有瞬态记录随即清空。

五、用户权利与撤销授权

您可以随时在操作系统的「系统设置 -> 隐私与安全性」中，随时关闭对 TransEase 的“屏幕录制”、“辅助功能”或“麦克风”授权。关闭相应授权后，依赖该权限的功能将优雅停用，不影响软件其他模块的正常运行。

六、未成年人保护

本软件为通用型生产力与学习辅助工具，不针对未成年人定向推广，也不会故意收集未成年人的任何个人身份信息。

七、隐私政策的更新与联系方式

随着透镜后续版本迭代以及 iOS / Android 移动端与 Windows 版的上线，我们可能会适时修订本隐私政策。任何实质性变更都会在官网主页公示。
